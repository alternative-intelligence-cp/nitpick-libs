# The workbench roadmap

The workbench's cycles are the versions of the `npk` plugin, because the
plugin *is* the working system: the skills, the agent definitions, the guard,
the hooks, and the documents the orchestrator runs on.

| Cycle | Plugin | What it is | State |
|---|---|---|---|
| 0.1 | 0.1.0 | the five original skills, the guard, the startup prompt, the board and the stream partition — written 2026-09-03 in the planning session | shipped, never run end to end |
| [0.2](0.2/README.md) | 0.2.0 | **the system made to run**: the contracts between roles, the worker rewritten for delegation, the loop with its stop list in one home, agent definitions, the guard extended to claims, compaction survival, the research skill, and the system's own dry run | planned |

Cycle numbers sort lexically only to `0.9`; this table is authoritative over
lexical order.
